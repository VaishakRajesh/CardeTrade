## Summary
Admins now get a dedicated navbar section linking to Admin dashboard, Recent Users, Recent Orders, PM Approvals, and Disputes. Two new admin pages were added: `/panel/orders/` lists all orders with a chevron that expands a row inline to show full details plus a "View full details" link; `/panel/users/` lists all users (rows link to user detail). The admin dashboard's Recent Users / Recent Orders / Open Disputes cards now have clickable rows and "View all" footers, and the Quick Actions card gained a Disputes button.

## Details
### panel/views.py
- `RecentOrdersView`: `Order.objects.all().select_related('buyer','seller','batch').order_by('-created_at')`, template `panel/orders/list.html`, `paginate_by=20`.
- `RecentUsersView`: `User.objects.all().order_by('-date_joined')`, template `panel/users/list.html`, `paginate_by=20`.
- Added top-level `from trader.models import Order` (was previously imported only locally inside `AdminDashboardView`).

### panel/urls.py
- `path('orders/', views.RecentOrdersView.as_view(), name='recent_orders')`
- `path('users/', views.RecentUsersView.as_view(), name='recent_users')`

### panel/templates/panel/orders/list.html (new)
- Each order row has a chevron `data-bs-toggle="collapse"` button targeting `#order-<pk>`; the collapsible row shows buyer, seller, batch, qty, price/kg, total, tracking-entry count, created date, and a "View full details" link to `trader:order_detail`.
- Reuses `card-premium`/`table-premium`/`btn-premium` styling and Django pagination (`is_paginated`, `page_obj`).

### panel/templates/panel/users/list.html (new)
- Table of users (username→`panel:user_detail`, role badge, email, joined, active/inactive badge) + pagination.

### panel/templates/panel/dashboard.html
- Recent Users card: footer "View all users" → `panel:recent_users` (rows already linked to `user_detail`).
- Recent Orders card: `order_code` now links to `trader:order_detail`; footer "View all orders" → `panel:recent_orders`.
- Open Disputes card: order code links to `panel:dispute_resolve`; footer "View all disputes" → `accounts:dispute_list`.
- Quick Actions: added "Disputes" button → `accounts:dispute_list`.

### templates/includes/navbar.html
- Admin users (previously matched no role branch) now see: Admin (`panel:dashboard`), Recent Users (`panel:recent_users`), Recent Orders (`panel:recent_orders`), PM Approvals (`panel:pm_pending_list`), Disputes (`accounts:dispute_list`). The global "Orders" link (all authenticated users) remains.
